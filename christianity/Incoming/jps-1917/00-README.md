# JPS 1917: the Hebrew Bible in English, one verse per line

**What this is.** *The Holy Scriptures According to the Masoretic Text: A New Translation* (Jewish Publication Society, 1917), from eBible.org's public-domain text, split into one file per book by `scripts/import-ebible.py`.

**Why it's here.** A public-domain Jewish translation of the Hebrew text, to set beside the KJV (Christian, 1611) and Brenton (from the Greek). Isaiah 7:14 "the young woman shall conceive" is the obvious case.

**Numbering is the Hebrew, as JPS prints it.** eBible distributes this text renumbered to the KJV with the JPS numbers inline; the import restores JPS's own numbers and puts the KJV number on any line where it differs, e.g. `**40:7** _(KJV 40:6)_ Sacrifice and meal-offering Thou hast no delight in`. Grep either.

**File order.** The order JPS prints: Law, Prophets, Writings (Chronicles last).

**How to cite.** `Hosea 6:6 (JPS 1917)`. Quote this file's wording.

**Source.** https://ebible.org/Scriptures/details.php?id=engjps (eBible source files dated 2025-12-12). **Rights:** public domain.

**Spot-check at import.** Spot-checked 2026-10-26: Hosea 6:6, Jeremiah 7:22, Isaiah 7:14, Psalm 2:7, Psalm 40:7 (= KJV 40:6), Psalm 51:3 (= KJV 51:1), Malachi 3:19 (= KJV 4:1) read as expected; not yet compared with a scan of the printed edition. Not yet audited verse-by-verse.
