# Inbox

What people have saved with `/nazbrain`. Anyone working in this repo in Claude Code can type it when a conversation turns up something worth keeping (Claude writes it up as a note), or hand Claude documents (PDF, Word, web pages, photos of pages) to convert to Markdown. Either way it lands here with the contributor's name and gets pushed. Copyrighted books come in as notes and short quotes only; the original goes to the NazBrain Google Drive folder.

**Nothing in this folder has been checked yet.** Each note says which findings came from a file in the repo and which are unchecked. Don't quote from here: check the source first (`VERIFIED-SOURCES.md`).

## Processing a note

1. Read it, and check each finding against the sources it names. A converted document: log it in the `PROCESSING-ROADMAP.md` inventory, and if it's a primary text, register it in `VERIFIED-SOURCES.md` and move it to the right folder.
2. Work what holds up into the research files, keeping the contributor's name in a `**Contributed by:**` line.
3. Possible problems in our existing research go to `AUDIT-LIST.md`; new questions to `OPEN-RESEARCH.md`.
4. Delete the note when it's done. Git keeps it in the history.
