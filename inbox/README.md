# Inbox

Conversation notes saved with `/nazbrain`. Anyone working in this repo in Claude Code can type `/nazbrain` when a thread turns up something worth keeping; Claude writes it up as a note here, with the contributor's name, and pushes it.

**Nothing in this folder has been checked yet.** Each note says which findings came from a file in the repo and which are unchecked. Don't quote from here: check the source first (`VERIFIED-SOURCES.md`).

## Processing a note

1. Read it, and check each finding against the sources it names.
2. Work what holds up into the research files, keeping the contributor's name in a `**Contributed by:**` line.
3. Possible problems in our existing research go to `AUDIT-LIST.md`; new questions to `OPEN-RESEARCH.md`.
4. Delete the note when it's done. Git keeps it in the history.
